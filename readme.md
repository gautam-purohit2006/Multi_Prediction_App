# 🧠 Multiple Prediction System

A Machine Learning web application built with **Flask** that combines multiple predictive models into a single platform. Users can access different prediction modules through a simple and responsive web interface.

---

## 📌 Project Overview

The Multiple Prediction System is an all-in-one machine learning application that provides predictions for various real-world problems. Each prediction module uses a trained machine learning model and allows users to enter input values through an intuitive interface.

## 📊 Prediction Modules

### 🚗 Car Price Prediction
Predicts the estimated selling price of a used car based on vehicle details.

### 💰 Gold Price Prediction
Predicts gold prices using historical and financial data.

### ❤️ Heart Disease Prediction
Predicts the likelihood of heart disease based on medical parameters.

### 🩺 Diabetes Prediction
Predicts whether a person is likely to have diabetes using health-related inputs.

### 📧 Spam Mail Detection
Classifies emails as **Spam** or **Not Spam** using Natural Language Processing (NLP).

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/gautam-purohit2006/Multi_Prediction_App.git
```

### Navigate to the Project Directory

```bash
cd multiple-prediction-system
```

### Create a Virtual Environment (Optional)

```bash
python -m venv venv
```

### Activate the Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### Install Required Packages

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
